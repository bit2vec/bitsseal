# 001: Binary Encoding

## Installation

```bash
# Create virtual environment
conda create -n binary_seb python=3.9
conda activate binary_seb

# Install dependencies
pip install -r requirements.txt

# Install package
pip install -e .
```

## Requirements

- Python >= 3.8
- PyTorch >= 2.0
- CUDA >= 11.8 (for GPU support)
- transformers >= 4.30
- datasets >= 2.0
- numpy, pandas, matplotlib, tqdm
